# OpenGym exercise catalog

Source: https://github.com/alexpcosta/opengym/blob/main/frontend/src/lib/exercises-data.js
Source blob: b7a697af857489448d5132dda281bb8cb317974c
Upstream dataset: https://github.com/hasaneyldrm/exercises-dataset

All 1324 data records are included, with original English names/instructions and stable opengym_ IDs. No OpenGym application code or media was copied. Dataset MIT license is included in the in-app exercise catalog notices.

Legacy and custom exercises are preserved, including existing plan/session references. Repeated seeding inserts only missing IDs. Broad MacroMate muscle/equipment groups are used for filtering; original target and equipment labels remain in each instruction. Adductors use the uncategorized/fullBody bucket until dedicated muscle groups are supported. Timed classification is a name-based heuristic for planks/static holds/hangs/wall sits/stretches, not source metadata.

Images/GIFs require separate rights from Gym visual and are deliberately not bundled or hotlinked.
