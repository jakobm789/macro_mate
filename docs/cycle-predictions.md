# Zyklusvorhersagen

Zyklusdaten werden lokal gespeichert. Die Vorhersage-Engine nutzt Periodenstarts, den Median gültiger Intervalle (21–45 Tage) und die durchschnittliche Blutungsdauer. Bei fehlender Historie werden die im Profil hinterlegten 28/5-Tage-Defaults verwendet.

Die Engine liefert nächste Periode, fruchtbares Fenster, Zyklustag, Konfidenz und eine maschinenlesbare Begründung. Konfidenz ist eine Unsicherheitsanzeige, keine medizinische Diagnose. Unregelmäßige oder fehlende Einträge senken die Konfidenz; die UI muss Prognosen als Schätzung kennzeichnen und darf keine Verhütungs- oder Therapieentscheidung daraus ableiten.

Symptome, Stimmung, Schmerz, Energie und Schlafqualität werden als Tageslogs mit lokaler Tagesgrenze gespeichert. Einträge können korrigiert oder gelöscht werden, ohne historische Rohdaten zu verändern.
